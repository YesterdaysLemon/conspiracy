# Contributing

Conspiracy is intentionally small. Contributions should preserve the central interaction: people and agents work on the same visible, reversible board.

1. Create a branch.
2. Run `npm install`.
3. Make a focused change.
4. Add or update tests for evidence semantics or WebMCP contracts.
5. Run `npm test` and `npm run build`.
6. Open a pull request with a short before/after description.

Please do not add real-person conspiracy datasets, opaque tracking, client-side provider secrets, or features that silently promote an agent proposal into accepted evidence.
